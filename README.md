# Вариант 1 — Консольный калькулятор

Программа выполняет арифметические операции: `+`, `-`, `*`, `/`, `//`, `%`, `^`.

## Новый функционал (практическая работа №2)

- Можно выполнять **несколько вычислений подряд**: после каждой операции программа спрашивает
  `Хотите выполнить ещё одну операцию? (да/нет):`.
- Программа корректно обрабатывает:
  - неправильную математическую операцию — просит ввести операцию ещё раз;
  - деление на ноль (для `/`, `//`, `%`) — выводит ошибку и предлагает продолжить;
  - некорректный ввод чисел — просит ввести число ещё раз;
  - неправильный ответ на вопрос о продолжении — просит ответить «да» или «нет».

## Запуск

```bash
python main.py
```

## Пример

```
Введите первое число: 10
Введите операцию (+, -, *, /, //, %, ^): *
Введите второе число: 5

Результат: 50

Хотите выполнить ещё одну операцию? (да/нет): да

Введите первое число: 100
Введите операцию (+, -, *, /, //, %, ^): /
Введите второе число: 4

Результат: 25

Хотите выполнить ещё одну операцию? (да/нет): нет

Работа программы завершена.
```
